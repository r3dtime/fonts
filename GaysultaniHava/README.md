# GaysultaniHava

*Элегантный и функциональный шрифт для веб-интерфейсов.*

## 👁️ Предпросмотр
![GaysultaniHava](/GaysultaniHava/GaysultaniHava.jpeg)

## ✨ Особенности
- **Поддержка языков:** Чеченский (Латиница + Кириллица).
- **Начертания:** Thin, ExtraLight, Light, Normal, Medium, SemiBold, Bold, ExtraBold, Black.

## 🚀 Установка
1. Скачайте файлы из папки `fonts/GaysultaniHava` (формат `.ttf`).
2. Установите в систему (двойной клик на файл -> "Установить").
3. Или подключите через CSS:
   ```css
   @font-face {
     font-family: 'MyFont';
     src: url('https://cdn.jsdelivr.net/gh/r3dtime/fonts@main/GaysultaniHava/GaysultaniHava_Normal.woff2') format('woff2');
   }
   ```
