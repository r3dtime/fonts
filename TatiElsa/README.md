# TatiElsa

*Элегантный и функциональный шрифт для веб-интерфейсов.*

## 👁️ Предпросмотр
![TatiElsa](/TatiElsa/TatiElsa.jpeg)

## ✨ Особенности
- **Поддержка языков:** Чеченский (Латиница + Кириллица).
- **Начертания:** Thin, ExtraLight, Light, Normal, Medium, SemiBold, Bold, ExtraBold, Black.

## 🚀 Установка
1. Скачайте файлы из папки `fonts/TatiElsa` (формат `.ttf`).
2. Установите в систему (двойной клик на файл -> "Установить").
3. Или подключите через CSS (если это веб-шрифт):
   ```css
   @font-face {
     font-family: 'MyFont';
     src: url('https://cdn.jsdelivr.net/gh/r3dtime/fonts@main/TatiElsa/TatiElsa.woff2') format('woff2');
   }
   ```
